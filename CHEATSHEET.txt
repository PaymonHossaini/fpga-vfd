┌─ QUICK WORKFLOW: ADD IMAGE TO DISPLAY ─────────────────────────────────────┐
│ 1. make test-pattern                    # Create test image                 │
│ 2. make image-rom IMAGE=test_pattern.png  # Convert to Verilog             │
│ 3. Update fpga_2_vfd.gprj to include:                                       │
│    - src/vfd_graphics_writer.v                                              │
│    - src/image_rom.v                                                        │
│ 4. make flash                           # Build & program                   │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ IMAGE CONVERSION ──────────────────────────────────────────────────────────┐

┌─ VFD DISPLAY COMMANDS (GU256x128C) ─────────────────────────────────────────┐
│ COMMAND              HEX     DESCRIPTION                                    │
│ ─────────────────────────────────────────────────────────────────────────── │
│ Clear Display        0x0C    Clear screen, cursor home                      │
│ Graphics Mode        0x02    Enter graphics mode                            │
│ Graphics Write       0x47    Start graphics write sequence                  │
│ Brightness           0x04    Set brightness (next byte: 0x00-0xFF)          │
│ Any ASCII char       0x20+   Write character to display                     │
│                                                                              │
│ Graphics Write Sequence:                                                    │
│   1. 0x47                    Graphics write command                         │
│   2. X_low, X_high           X position (0-255)                             │
│   3. Y                       Y position (0-127)                             │
│   4. Width_low, Width_high   Image width                                    │
│   5. Height                  Image height                                   │
│   6. [pixel data...]         width×height/8 bytes                           │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ TIMING PROTOCOL ───────────────────────────────────────────────────────────┐
│ 1. Wait for READY = HIGH                                                    │
│ 2. Place data on data_bus[7:0]                                              │
│ 3. Assert WR = LOW (hold for ~5 clock cycles @ 27 MHz)                     │
│ 4. Release WR = HIGH                                                        │
│ 5. Repeat for next byte                                                     │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ TROUBLESHOOTING ───────────────────────────────────────────────────────────┐
│ PROBLEM                          SOLUTION                                   │
│ ─────────────────────────────────────────────────────────────────────────── │
│ "gw_sh not found"                Add Gowin to PATH in ~/.bashrc             │
│ "openFPGALoader not found"       sudo apt install openFPGALoader            │
│ FPGA not detected                sudo usermod -a -G plugdev $USER           │
│ Display shows garbage            Check level shifters (3.3V ↔ 5V)           │
│ Image doesn't appear             Verify image_rom.v is in project           │
│ Characters work, images don't    Check graphics mode sequence (VFD_COMMANDS)│
└──────────────────────────────────────────────────────────────────────────────┘

┌─ PINOUT (see vfd_parallel_interface.cst) ───────────────────────────────────┐
│ SIGNAL        FPGA PIN    VFD PIN      NOTES                                │
│ ─────────────────────────────────────────────────────────────────────────── │
│ data_bus[7:0] Various     CN4 1-8      8-bit data bus (use level shifter)  │
│ wr_n          TBD          CN4 10      Write strobe (active low)            │
│ ready         TBD          CN4 12      Ready signal from VFD                │
│                                                                              │
│ ⚠️  VFD operates at 5V logic - use level shifters with 3.3V FPGA!          │
